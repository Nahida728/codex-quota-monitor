# Codex 额度检测器

一个透明无边框、可拖动、始终置顶的 Windows 桌面悬浮卡片，用于读取本机 Codex 的真实额度状态。

> 非官方社区项目，与 OpenAI 无隶属或背书关系。Codex、OpenAI 及相关图标是其各自权利人的商标或资产。

## 功能

- 5 小时额度及恢复时间；官方未返回该窗口时显示“官方暂未启用”
- 1 周额度及恢复时间
- 可用重置次数、重置类型、最近到期时间
- 检测安装后新增的重置次数
- 检测官方全额度重置：Codex 在线、两个额度窗口同时恢复 100%，且均未到正常恢复时间
- Codex / OpenAI 联机状态与中国大陆网络提示
- 中英文切换、位置锁定/自由拖动、托盘置顶开关、60 秒自动刷新
- 标题栏和四条窗口边缘均可拖动；锁定后所有移动热区同时停用
- 背景图支持点击选择或直接拖入，原图宽、高必须分别大于 460 × 690
- 固定 460:690 比例的选框支持移动、缩放，截取后可调背景透明度或一键恢复默认
- 凭据只由 Codex app-server 使用，不进入渲染进程，也不会写入日志

## 开发运行

要求已安装并登录 Codex，且本机有 Node.js 20+。

```powershell
npm install
npm start
```

## 打包

```powershell
npm run build
```

构建结果位于 `release` 目录，包括便携版和安装版。

图钉按钮只控制卡片位置是否锁定；“始终置顶”可在托盘右键菜单中单独控制。窗口固定为 460 × 690，卡片贴合窗口且不启用系统外阴影。标题栏和四条 22px 宽的可见边缘均使用 Electron 原生拖动区域，不运行自定义逐帧移动逻辑；锁定后这些拖动区域同时停用。

## 检测说明

应用通过本机 Codex app-server 的 `account/rateLimits/read` 读取服务端额度。窗口类型按服务端的 `windowDurationMins` 识别，避免 5 小时窗口关闭后把 1 周窗口误当成短周期额度。

“官方额度重置”严格按连续快照推断：Codex 在线、5 小时和 1 周额度同时突然恢复为 100%，且两者都未到各自正常恢复时间时，才判定为官方重置所有限额。5 小时窗口被官方关闭时不会作此判定。首次运行只建立基线，不会把已有重置次数误报为新增。
